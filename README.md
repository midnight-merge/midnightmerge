# midnightmerge.dev

Static site for [midnightmerge.dev](https://midnightmerge.dev), served by GitHub Pages
from the `main` branch root. No build step.

- `index.html` — project index
- `members.html` — roster
- `style.css` — shared styles
- `CNAME` — custom domain

## Deploy

Push to `main`. In repo Settings → Pages, set Source to "Deploy from a branch",
branch `main`, folder `/ (root)`, and confirm the custom domain reads
`midnightmerge.dev`.
